# Vayura Frontend

Production-oriented frontend foundation for Vayura AI.

## Stack
- React + TypeScript + Vite
- Ant Design UI
- React Router
- TanStack Query

## Commands
- `npm run dev`
- `npm run build`
- `npm run lint`
